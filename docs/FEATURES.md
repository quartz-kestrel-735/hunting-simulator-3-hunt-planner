# Hunting Simulator 3 Hunt Planner — feature reference

The Hunting Simulator 3 hunt planner workflow separates equipment groups from route notes and session records. Named sections make the available options easier to find.

| Section | Description |
|---|---|
| Equipment groups | Equipment categories and the associated selection or configuration options. |
| Route notes | Route stages, transport context, and the notes associated with each part of the journey. |
| Session records | Session and activity information grouped by the task or context it belongs to. |

The project page follows the same section structure.
